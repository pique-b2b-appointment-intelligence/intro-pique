# Opvolging - 4 mails (Je keek even)

Vier scanners, zelfde format en hetzelfde script (OpvolgConcepten-Batch3c.gs). Onderwerp: 'Je keek even, [voornaam]'.

## Stappen
1. Plak de rijen uit **Opvolging-Batch3f-Data.csv** onder je Opvolging-tabblad (zonder kopregel).
2. Menu **BCS opvolging -> Zet concepten klaar**. Alleen deze nieuwe worden gemaakt.
3. Nalezen en versturen.
